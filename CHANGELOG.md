# Changelog

## 0.1.0

- Initial Windows Tauri application with French/English interface and light/dark/system themes.
- Local SQLite persistence, rule conditions, preview, no-overwrite moves and rename.
- Integrity-checked undo, interrupted-operation safe mode and folder watching.
- Tray, optional Windows startup, summary notifications and NSIS configuration.
- Windows CI and a gated signed-release pipeline; production updater requires owner-provided keys.
